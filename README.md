# Mostros Mix

Juego para armar mostros mezclando partes: cuernos, orejas, ojos, boca, cuerpo, alas, cola y patas.
Basado en los dibujos del "Mostro Cornio".

## Qué se puede hacer

- Elegir cada parte o tirar el dado para un mix al azar.
- Pintarlo y ponerle nombre.
- Arrancar desde los Mostros clásicos o los Mostros mitológicos (con su ficha y su historia).
- Guardar los favoritos en "Mi colección" (queda guardada en ese dispositivo).
- Ver las características de cada parte.
- Compartir el mostro: en el teléfono abre el menú de compartir (WhatsApp, etc.); en la compu ofrece WhatsApp o copiar el link.
  El link abre exactamente el mismo mostro.

## Cómo está hecho

Es un único archivo `index.html`, sin dependencias ni compilación: los dibujos son SVG generados con JavaScript.
Para probarlo alcanza con abrir `index.html` en el navegador.

## Publicarlo con GitHub Pages

Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
A los pocos minutos queda en `https://<usuario>.github.io/mostros-mix/`.
